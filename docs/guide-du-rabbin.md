# Guide du site : mode d'emploi

*Pour gérer le site du Beth Habad depuis votre téléphone, en quelques gestes.*

---

## 1. Se connecter (pas de mot de passe)

1. Ouvrez **https://beth-habad-montmagny.vercel.app/admin** (adresse provisoire, en attendant le nom de domaine) sur votre téléphone.
2. Tapez votre adresse e-mail, puis appuyez sur **« Recevoir mon lien de connexion »**.
3. Ouvrez l'e-mail reçu et appuyez sur **« Me connecter »**. C'est tout.

> Pas d'e-mail ? Regardez dans « Courrier indésirable ». Le lien est valable 1 heure.

**Astuce : mettre l'admin sur l'écran d'accueil**, comme une application.
- iPhone (Safari) : bouton **Partager** → **Sur l'écran d'accueil**.
- Android (Chrome) : menu **⋮** → **Ajouter à l'écran d'accueil** (ou **Installer**).

Depuis l'icône « Admin Beth Habad », si on vous demande un code, saisissez celui de l'e-mail.

---

## 2. Ajouter un événement

1. Tableau de bord → **« Ajouter un événement »**.
2. Remplissez : **titre**, **date**, **heure de début** (le reste est facultatif).
3. Ajoutez une photo : **« Prendre ou choisir une photo »** (appareil photo ou galerie).
4. Pour les inscriptions en ligne : cochez **« Inscription en ligne »** et, si besoin, le nombre de places.
5. Appuyez sur **« Publier »**. L'événement est en ligne immédiatement.

- **Aperçu** : voir le résultat avant de publier.
- **Brouillon** : enregistrer sans publier.
- Pour un événement **CTeen**, choisissez « CTeen » dans « Type d'événement ».
- **Dupliquer** (dans la liste) : pratique pour un événement qui revient chaque année.

---

## 3. Les horaires de Chabbat : la page « Ce Chabbat »

Le site prépare chaque semaine **le même message que celui que vous envoyiez sur WhatsApp** : allumage, Minha suivi d'Arvit, Tania, Chaharit, Cours, Minha, Fin, Arvit, « Chabbat Chalom ». Les heures sont **calculées automatiquement**. Les fêtes (Roch Hachana, Kippour, Souccot, Pessa'h, Chavouot…) apparaissent dans la même page, au même format.

1. Tableau de bord → **« Horaires de ce Chabbat »**.
2. En haut, choisissez la semaine (ou la fête) si ce n'est pas la bonne.
3. Changez seulement ce qui est différent cette semaine :
   - une **heure** : touchez-la et corrigez-la (videz-la pour revenir au calcul) ;
   - une ligne à **retirer** cette semaine : décochez « Afficher » ;
   - le **Kidouch** : écrivez par exemple « Grand Kidouch 🍷 offert par la famille … ». Laissé vide, il n'apparaît pas ;
   - une ligne en plus (cours spécial, office supplémentaire) : **« Ajouter une ligne »** ;
   - une **note** libre, qui s'affiche avant « Chabbat Chalom ».
4. **« Enregistrer les horaires »** : le site est à jour tout de suite.
5. **« Copier le message WhatsApp »**, puis collez-le dans les groupes. Ou **« Partager sur WhatsApp »** pour l'envoyer directement.

Rien à faire la semaine suivante : tout repart du calcul. Pour changer les heures **de toutes les semaines** (Chaharit à 9h, Minha 30 minutes avant la Fin en hiver…) : Menu → **« Règles de calcul des horaires »**.

**Offices de la semaine** (dimanche, lundi au vendredi matin) :
1. Menu → **« Offices de la semaine »**.
2. Appuyez sur **« Modifier »** sous l'horaire, changez l'heure, **« Enregistrer »**.
3. Pour une note générale (« Horaires d'été »), utilisez le champ tout en haut.

---

## 4. Publier une annonce (bandeau en haut du site)

1. Tableau de bord → **« Publier une annonce »**.
2. Écrivez le texte (court), choisissez la couleur.
3. Facultatif : une **date de disparition** (l'annonce s'enlève toute seule).
4. **« Enregistrer »**. Pour la retirer avant : **« Masquer »** dans la liste.

---

## 5. Ajouter des photos

1. Tableau de bord → **« Ajouter des photos »**.
2. **Nouvel album** : « Créer un nouvel album », donnez un titre, **« Créer l'album et ajouter des photos »**.
   **Album existant** : appuyez simplement dessus.
3. **« Ajouter des photos »** : prenez une photo ou choisissez-en **plusieurs** dans votre galerie. Gardez la page ouverte pendant l'envoi.
4. Quand c'est prêt : **« Publier l'album »**.

Les photos sont automatiquement allégées : pas besoin de les réduire avant.

---

## 6. Inscriptions et messages

- **« Voir les inscriptions »** : la liste par événement, le nombre total de personnes, **« Télécharger (Excel) »** et **« Partager sur WhatsApp »**.
- **« Voir les messages »** : les messages du formulaire de contact, avec les boutons **Répondre**, **Appeler** ou **WhatsApp**.

**Être prévenu sur le téléphone** à chaque nouveau message ou inscription :
1. iPhone : ouvrez l'admin **depuis l'icône de l'écran d'accueil** (voir la partie 1), sinon l'iPhone ne permet pas les notifications.
2. En haut du tableau de bord, appuyez sur **« Activer les notifications »**, puis sur **« Autoriser »**.
3. Une notification d'essai arrive aussitôt. En la touchant, vous arrivez sur le message ou l'inscription.

À faire sur chaque téléphone qui doit être prévenu. **« Désactiver »** les arrête sur ce téléphone.

---

## Bon à savoir

- **Rien n'est perdu** : un élément supprimé va dans la **Corbeille** (menu), où il reste 30 jours. Appuyez sur **« Restaurer »** pour le récupérer.
- **Les textes des pages** (présentation, le rabbin, CTeen…) se modifient dans **Menu → Textes des pages**. Remplacez les passages marqués **[À COMPLÉTER]**.
- **Ajouter une personne** pour vous aider : **Menu → Équipe → Ajouter quelqu'un**.
- **Le lien du don, le téléphone, WhatsApp, les réseaux sociaux** : **Menu → Paramètres**.
- Un message rouge s'affiche ? Il indique ce qu'il faut corriger. En cas de doute : **[contact du développeur]**.
